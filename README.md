# イジンデン一人回し（デッキ構築 & ソロプレイ卓上アシスタント）

ブースター第1〜6弾、576枚のカードデータを内蔵した、非公式のファンメイド Web アプリです。
ビルド不要・サーバー不要で、ブラウザだけで動作します。

## 使い方（すぐ試す）

`index.html` をダブルクリックしてブラウザで開くだけで動作します。

## 配布・公開する場合

このフォルダ一式（index.html / style.css / app.js / cards-data.js）を、
GitHub Pages・Netlify・Vercel などの静的サイトホスティングにそのままアップロードすれば公開できます。
ビルドコマンドは不要です。フォルダ内のファイル構成を変えずにアップロードしてください。

## できること

### デッキ構築タブ
- 576枚のカードを 名前/テキスト検索・種類・色・レベル・収録弾・レアリティ で絞り込み
- 40枚以上・同名カード4枚まで（「デッキに何枚でも入れてよい」カードは例外）のルールに沿ってデッキを作成
- デッキはブラウザ内（localStorage）に保存され、次回起動時も残ります
- テキスト形式での書き出し・読み込みにも対応（バックアップや共有用）

### ソロプレイタブ（1人回し）
- 保存したデッキを選んで対戦準備（シャッフル・手札6枚・ガーディアン4枚を自動配置）
- ターン・フェイズ（スタート/ドロー/メイン/エンド）の進行、
  マリョク配置権・イジン召喚権のリセット、山札からのドローを自動化
- 手札・魔力ゾーン・戦場・墓地の各カードをクリックすると、そのカードでできる操作
  （マリョク配置・イジン召喚・ハイケイ使用・マホウ使用・起こす/寝かせる・表裏変更・
  各ゾーンへの移動）のメニューが出ます
- 魔力ゾーンの「使用可能な色・レベル上限」は自動計算されます

**重要な注意点：** このアプリは盤面・ゾーン・リソースの管理を自動化するものであり、
各カード固有の効果（ルールテキストの内容）は自動で判定・実行されません。
効果の適用は、必ずカード詳細（クリックで確認可能）のルールテキストをご自身で読みながら、
上記のゾーン移動操作を使って手動で反映してください。

## データについて

同梱の `cards-data.js` は、提供いただいた第1〜6弾のカードリスト（Excel）から自動生成しました。
元データにはカードの「種類」列が無かったため、パワー・レベル欄・ルールテキストの記載内容から
イジン / マホウ / ハイケイ / マリョク を自動推定しています。推定が難しいカードは、
まれに誤分類されている可能性があります。デッキ構築画面のカード詳細で種類が明らかにおかしい場合は、
実物のカードを見て判断してください（本アプリのソースコード `cards-data.js` 内の `type` の値を
直接書き換えることでも修正できます）。
