# イジンデン一人回し（デッキ構築 & ソロプレイ卓上アシスタント & CPU対戦）

ブースター第1〜6弾、576枚のカードデータを内蔵した、非公式のファンメイド Web アプリです。
ビルド不要・サーバー不要で、ブラウザだけで動作します。

## ▶ 今すぐ遊ぶ

**https://thailandueda.github.io/ijinden-play/**

上のURLを開くだけで、PC・スマホのブラウザからすぐに遊べます（インストール不要・無料）。
デッキや設定は、お使いのブラウザに保存されます。

### 📲 スマホのホーム画面に追加して、アプリのように使う

ホーム画面にアイコンが置かれ、アドレスバーなしの全画面で開けます。一度開いておけば、電波がない場所でも遊べます。

- **iPhone（Safari）**：画面下の共有ボタン（□に↑）→「ホーム画面に追加」→「追加」
- **Android（Chrome）**：右上の「︙」→「ホーム画面に追加」または「アプリをインストール」

更新はオンラインで開いたときに自動で反映されます。

それでは、ダイブをお楽しみください。

## 手元のPCで使う（オフライン）

当画面の「code」ボタンから「Download ZIP」を選択して、ローカルにzipファイルを保存。
その後zipファイルを展開して、index.html をブラウザで開くと動作します。
※展開せずにzipファイルの中でindex.htmlを開いても動作しません。zipファイルを展開してからご利用ください。

`index.html` をダブルクリックしてブラウザで開くだけで動作します。

## 配布・公開する場合

このフォルダ一式を、GitHub Pages・Netlify・Vercel などの静的サイトホスティングにそのままアップロードすれば公開できます。
ビルドコマンドは不要です。フォルダ内のファイル構成を変えずにアップロードしてください。

## できること

### デッキ構築タブ
- 576枚のカードを 名前/テキスト検索・種類・色・レベル・収録弾・レアリティ で絞り込み
- 40枚以上・同名カード4枚まで（「デッキに何枚でも入れてよい」カードは例外）のルールに沿ってデッキを作成
- デッキはブラウザ内（localStorage）に保存され、次回起動時も残ります
- テキスト形式での書き出し・読み込みにも対応（バックアップや共有用）

### ソロプレイタブ（1人回し）
- 保存したデッキを選んで対戦準備（シャッフル・手札6枚・ガーディアン4枚を自動配置）
- ターン・フェイズ（スタート/ドロー/メイン/エンド）の進行、
  マリョク配置権・イジン召喚権のリセット、山札からのドローを自動化
- 手札・魔力ゾーン・戦場・墓地の各カードをクリックすると、そのカードでできる操作
  （マリョク配置・イジン召喚・ハイケイ使用・マホウ使用・起こす/寝かせる・表裏変更・
  各ゾーンへの移動）のメニューが出ます
- 魔力ゾーンの「使用可能な色・レベル上限」は自動計算されます

### CPU対戦
- デッキ構築した後、プリセットされているデッキとの対戦が可能です。
- 自分でデッキ構築した場合も、対戦相手として選ぶことが可能です。
- あくまでも「ソロプレイの自動化」程度に考えてもらえると助かります。強さはデッキによって差があります。
- とりあえず変な事せずに動く、を目標に作っておりますので、温かい目でみてください。

**重要な注意点：** 
- このアプリは盤面・ゾーン・リソースの管理を自動化するものです。
あなたのカードの効果は、カード詳細（クリックで確認可能）のルールテキストを見ながら、
上記のゾーン移動操作を使って手動で処理してください。
CPUのカード効果と、両者に効く一部の常在能力は自動で処理されます。
- CPU対戦は全自動ではありません。複雑なルールに対応するべく、ある程度手動での操作ありきで設計しております。

## データについて

同梱の `cards-data.js` は、提供いただいた第1〜6弾のカードリスト（Excel）から自動生成しました。
元データにはカードの「種類」列が無かったため、パワー・レベル欄・ルールテキストの記載内容から
イジン / マホウ / ハイケイ / マリョク を自動推定しています。推定が難しいカードは、
まれに誤分類されている可能性があります。デッキ構築画面のカード詳細で種類が明らかにおかしい場合は、
実物のカードを見て判断してください（本アプリのソースコード `cards-data.js` 内の `type` の値を
直接書き換えることでも修正できます）。

### ルール・カード効果（あなた・CPUの両方に適用）
- 同時に発動待ちになった能力は、ターンプレイヤーの能力から先に処理するようにした（ハイケイ配置時の執筆、イジンが破壊されたときの能力）。先に処理した能力でカードが戦場を離れたり裏になったりしたら、そのカードの能力は発動しない
- あなたのターンに、あなたの執筆（手動処理）とCPUの執筆が同時に発動したときは、CPUの能力を「待機中」として表示し、あなたが処理し終えてから発動する（ボタン、または次の行動で発動）
- 武帝の「イジン1体につき」に、円形闘技場でイジンになっているガーディアンも数えるようにした
- クリストファー・コロンブスで「召喚権+1」を選ぶとエラーになる不具合を修正
- 常在能力・ロック効果を自動で適用。主なもの：
  - 戦場に置かれる・アタック・ブロック：グスタフ2世アドルフ、玄宗、魔除けの社、孔子、永遠の帝都
  - 魔力ゾーン：ピラー、オリーブの枝
  - 能力を失わせる：黒田官兵衛、藤原不比等、小林虎三郎
  - 使用の制限：マルティン・ルター、ソクラテス、和宮、禁制の御殿
  - 剣術・プレッシャー：武者の蔵、風林火山、武田信玄、吉田松陰
  - その他：喀血の流行り病
- 勝利・敗北条件を自動判定：アイザック・ニュートン、大日本沿海輿地全図、ジョバンニ＝ディ＝メディチ、ファイナルアタック
- 自動計算するレベル軽減を追加：姜維、鴨長明、アルキメデス、豊臣秀吉、葛飾応為、アイオン、大日本沿海輿地全図

### CPU対戦
- CPUの判断をルールベースで強化：詰みの判定、安全なアタック、ブロックの割り振り、マリョク配置の色選び、召喚の優先順位
- CPUがマホウ・ハイケイも使うように
- プリセットデッキ全62個（第1〜6弾・デッキコンテスト）について、CPUのカード効果を100%自動処理
  - 「どれを選ぶか」「いつ使うか」はデッキごとの狙いに合わせて判断（例：スカーレット執筆の輿地全図ロック、紫微垣チャージ、リンボラース、利休エンビーのループなど）
  - デッキの勝ち筋に合わせた動き：ニュートンで手札をためる、LOデッキで相手の山札を削る、輿地全図でハイケイを並べる など
- 一部の任意効果は、CPUがあえて使いません（装備の多く、頼通＋レクイエムの無限コンボなど）
- プリセット更新：清少納言ロック、スカーレット執筆（2025/9版）のデッキリストを修正

### 既知の課題
- コンボ寄りのデッキ（ハースストーン、ハースストウ、ニュートンタイム、LO系など）は、CPUではまだ勝率が低め
- 千利休は大会で使用禁止。利休エンビーは参考用に残しています
